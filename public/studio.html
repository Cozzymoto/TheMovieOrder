      Where it goes
      1. Click Download. You get one file named after the franchise.
      2. Click Upload to GitHub — it opens the right folder for you.
      3. Drag the file in and commit. Same name replaces the old version.
      4. That's it. The page builds itself. Nothing else to edit.

      If anything is wrong, the build stops and names this file rather than publishing a broken page.
